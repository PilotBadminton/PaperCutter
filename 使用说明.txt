切题辅助应用说明：

本应用是基于 Windows 系统与 Python 语言开发，可以在 Windows10 及以上版本中稳定运行的切题辅助应用
其核心功能为：打开任意图片（支持JPG、JPEG、PNG、BMP格式）或PDF文档，将其内容展示在简洁的交互界面中。允许用户进行快速选区、切割、合并与自由编排，并将生成的图片保存于指定文件夹中
由于本应用默认为切割试卷提供服务，故导出切割图片生成的文件夹名称即为用户打开的图片/文档的文件名
用户可选择【切割题目】/【切割答案】模式，这将决定切割形成的图片的文件名以【题目】还是【答案】开头
亦可在【导出命名】栏目内输入自定义前缀，使其替换掉【题目】/【答案】作为文件名的开头
题号可以任意输入，汉字，英文字母与数字均可。若选择【导出成功后题号自动+1】，则每次成功导出一份内容后，题号末尾的数字都会+1，题号末尾无数字则生成1，并可递增
例如，若题号为【001】，则成功导出内容后变为【002】；若题号为【AAA数学题】，则成功导出内容后变为【AAA数学题1】
标准的切割后图片名格式为【题目/答案_题号.png】
若输入自定义前缀【物理】，则图片名格式变为【物理_题号.png】

使用流程：
①在dist文件夹中，找到【切题辅助应用.exe】，打开该应用程序
②在程序内界面点击位于左上角的“打开”，随后从本地选择任意图片或PDF文档
③设置页码和缩放倍率，使图像呈现出用户期望的状态
④在【选区工具】中选择【矩形】或【自由套索】。默认工具为【矩形】。若选择【自由套索】，则可以在图像区域按住鼠标左键自由绘制选区轮廓，松开鼠标后轮廓会自动闭合
⑤点击”开始选区“，随后在图像区域拖动鼠标，绘制选区。若画错，重新开始选区即可覆盖当前选区
⑥在【切割题目】/【切割答案】两个模式中任选其一，在”题号“下方的输入框内输入题号，点击”输出文件夹“下方的”选择文件夹“，从本地选择任意文件夹作为输出文件夹
⑦点击”确定切割“，等待图片被生成于输出文件夹

关于自由套索：
【自由套索】生成的图片仍然以外接矩形作为图片尺寸，但轮廓外的部分可以处理为透明或白底
在【自由轮廓外】栏目中选择【透明】，则直接导出的PNG会保留透明区域。选择【白底】，则轮廓外会被填充为白色
普通【合并导出】仍然使用白色背景，便于复制到Word或试卷文档中
【自由编排】内的背景则由自由编排窗口自己的背景设置决定

本应用还支持将位于同一PDF文件内不同页数的内容切割重组为一张图片。需要在完成①→⑥后，点击”添加到选区“，将当前选区保存到”已选区域“栏中
随后，重复③→⑤，创建更多选区。待所有选区创建完毕后，点击”合并导出“。”已选区域“栏中的所有选区会被自动拼合成一张图像，出现在指定的输出文件夹中
若选区为自由套索选区，”已选区域“栏会显示【自由】标记，并显示裁切后的预览图

当一份及以上选区被添加到”已选区域“栏中，【自由编排】功能将处于可用状态
该功能允许用户在一张可无限拓展的画布内自由布置选区，自由选择背景填充颜色，最终导出为一张拼接PNG图片
既可直接点击【可用选区】栏内的选区块，长按鼠标左键将其拖动至画布内释放，也可点击屏幕左下角的【添加到画布中心】按钮自动将其加入画布
同一选区可以在画布中被创建多份，所有被加入画布的选区都会参与导出。可以在画布内通过鼠标单击或绘制选择框的方式选中指定选区，按下delete键将其删除
自由编排窗口支持放大、缩小、100%、适应内容、最大化与全屏。全屏状态下按Esc可以退出全屏
在自由编排画布内，按住Space并拖动鼠标可以平移画布，按住Ctrl并滚动鼠标滚轮可以缩放画布
选区被拖动时，画布会显示边缘与中心参考线。若不希望吸附参考线，可在拖动时按住Alt
单独选中一个选区时，选区上方会显示旋转控制柄，拖动该控制柄即可围绕选区中心旋转
自由编排工具栏中的【上移】【下移】【置顶】【置底】可调整选区层级，层级越高的选区会显示在越上方，也会在导出时后绘制
选中选区后，可用方向键进行1px微调，按住Shift再按方向键可进行10px微调
自由编排支持透明背景、白色背景、自定义颜色背景与吸管取色。导出边距可以调整，边距为0时导出范围紧贴所有画布对象的外接范围
自由编排中的添加、移动、删除、清空、背景变化、边距变化、旋转、层级调整与键盘微调均支持撤销与恢复

快捷键一览：
打开文件  Ctrl + O
上一页     Ctrl + Left
下一页     Ctrl + Right
放大        Ctrl + +
缩小        Ctrl + -
放大/缩小（自由编排） Ctrl + 鼠标滚轮
平移画布（自由编排） Space + 鼠标拖动
禁用吸附（自由编排） Alt + 拖动选区
撤销（自由编排） Ctrl + Z
恢复（自由编排） Ctrl + Y
删除选区（自由编排） Delete
微调选区（自由编排） 方向键
快速微调（自由编排） Shift + 方向键
切换全屏（自由编排） F11
退出全屏（自由编排） Esc

本应用涉及的Python库：PySide6 ; PyMuPDF ; Pillow ; Pyinstaller
